 Command Line Interface — IDM_VTON

Upstream: https://github.com/yisol/IDM-VTON

 Anticloud CLI

bash
 Install
pip install anticloud-idm-vton

 Run offline with PAX inference
anticloud-idm-vton --offline --pax-local

 Run with AIOSS logging
anticloud-idm-vton --aioss-log ./ledger.jsonl

 Single binary (after build)
./idm_vton --config config.yaml


 Options

| Flag | Description |
| --- | --- |
| --offline | Disable all network calls |
| --pax-local | Use local PAX inference at 127.0.0.1:11434 |
| --aioss-log PATH | Write AIOSS audit chain to PATH |
| --encrypt | Enable AES-256 at rest for output files |
| --gpu | Force GPU inference |
| --cpu | Force CPU inference |
| --config PATH | Load configuration from YAML file |
